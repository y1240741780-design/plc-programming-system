# PLC 编程最佳实践与安全准则

## 编程规范

### 1. 变量命名
- 使用帕斯卡命名法：`MotorStart`, `ConveyorSpeed`
- IO 点加前缀：`DI_StartButton`, `DO_MotorOutput`
- 定时器加后缀：`Tmr_Delay`
- 避免单字母变量（循环变量除外）

### 2. 代码组织
```
PROGRAM Main
VAR
    // === IO 映射 ===
    // === 内部变量 ===
    // === 定时器/计数器 ===
END_VAR
    // === 初始化 ===
    // === 主逻辑 ===
    // === 安全保护 ===
    // === 报警诊断 ===
END_PROGRAM
```

### 3. 注释规范
- 每个功能块前添加说明注释
- 复杂算法添加公式说明
- IO 点必须注释用途

## 安全准则

### 1. 急停处理（最高优先级）
```st
IF EmergencyStop THEN
    // 停止所有输出
    Motor1 := FALSE;
    Motor2 := FALSE;
    Valve1 := FALSE;
END_IF;
```

### 2. 互锁保护
```st
// 正反转互锁
IF ForwardCmd AND NOT ReverseRunning THEN
    Forward := TRUE;
END_IF;
IF ReverseCmd AND NOT ForwardRunning THEN
    Reverse := TRUE;
END_IF;
```

### 3. 上电初始化
```st
IF FirstScan THEN
    // 初始化所有输出为安全状态
    AllOutputs := FALSE;
    FirstScan := FALSE;
END_IF;
```

### 4. 看门狗
```st
WatchdogTimer(IN := TRUE, PT := T#100MS);
IF WatchdogTimer.Q THEN
    Fault := TRUE;
    // 安全停机
END_IF;
```

### 5. 模拟量范围检查
```st
IF AnalogInput < MinValue OR AnalogInput > MaxValue THEN
    SensorFault := TRUE;
    AnalogInput := SafeValue;  // 使用安全替代值
END_IF;
```

## 常见陷阱

| 陷阱 | 说明 | 解决方案 |
|------|------|----------|
| 竞争条件 | 多个程序修改同一变量 | 明确任务优先级 |
| 死循环 | FOR/WHILE 无退出条件 | 添加循环次数限制 |
| 除零错误 | 未检查除数 | 判断 `IF divisor <> 0 THEN` |
| 数组越界 | 索引超出范围 | 判断 `IF index <= MAX THEN` |
| 浮点比较 | `IF a = 1.0` 不可靠 | 使用 `ABS(a - 1.0) < 0.001` |

## 调试技巧

1. **分步测试**：先测试 IO 映射，再测试逻辑
2. **状态监控**：关键变量添加趋势图
3. **强制变量**：测试时可用强制功能模拟输入
4. **交叉引用**：修改前检查变量所有引用位置
