# PLC 平台 ST 语法差异对照表

## IO 地址格式

| 平台 | 输入 | 输出 | 内部继电器 | 数据寄存器 |
|------|------|------|------------|------------|
| Siemens | `%I0.0` | `%Q0.0` | `%M0.0` | `%DB1.DBW0` |
| Beckhoff | `AT %I*` | `AT %Q*` | `AT %M*` | - |
| CODESYS | `AT %I*` | `AT %Q*` | `AT %M*` | - |
| Allen-Bradley | 标签 | 标签 | 标签 | 标签 |
| Mitsubishi | `X0` | `Y0` | `M0` | `D0` |
| Omron | `%0.0` | `%100.0` | `W0.0` | `D0` |

## 注释语法

| 平台 | 行注释 | 块注释 |
|------|--------|--------|
| Siemens | `//` | `(* *)` |
| Beckhoff | `//` | `(* *)` |
| CODESYS | `//` | `(* *)` |
| Allen-Bradley | `//` | `(* *)` |
| Mitsubishi | `(* *)` | `(* *)` |

## 定时器/计数器

| 平台 | 定时器 | 计数器 |
|------|--------|--------|
| Siemens | `TON`, `TOF`, `TP` | `CTU`, `CTD`, `CTUD` |
| Beckhoff | `TON`, `TOF`, `TP` | `CTU`, `CTD`, `CTUD` |
| CODESYS | `TON`, `TOF`, `TP` | `CTU`, `CTD`, `CTUD` |
| Allen-Bradley | `TON`, `TOF`, `RTO` | `CTU`, `CTD` |
| Mitsubishi | `TIM`(线圈) | `CNT`(线圈) |

## 边沿检测

| 平台 | 上升沿 | 下降沿 |
|------|--------|--------|
| Siemens | `R_TRIG` | `F_TRIG` |
| Beckhoff | `R_TRIG` | `F_TRIG` |
| CODESYS | `R_TRIG` | `F_TRIG` |
| Allen-Bradley | `ONS` | `OSF` |
| Mitsubishi | `PLS` | `PLF` |

## 程序组织单元 (POU)

| 平台 | 程序 | 功能块 | 函数 | 扩展名 |
|------|------|--------|------|--------|
| Siemens | OB/FC/FB | FB | FC | `.scl` |
| Beckhoff | PROGRAM | FUNCTION_BLOCK | FUNCTION | `.TcPOU` |
| CODESYS | PROGRAM | FUNCTION_BLOCK | FUNCTION | `.exp` |
| Allen-Bradley | Program | AOI | - | `.L5X` |
| Mitsubishi | Program | FB | FUN | `.st` |

## 数据块 / 全局变量

| 平台 | 方式 |
|------|------|
| Siemens | `DB` (数据块) + `VAR_GLOBAL` |
| Beckhoff | `GVL` (全局变量表) |
| CODESYS | `GVL` (全局变量表) |
| Allen-Bradley | Controller Tags |
| Mitsubishi | 全局标签 |
